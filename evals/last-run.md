# v0.2.0 试写与修订记录

日期：2026-10-26。触发：用户反馈 v0.1.0 的麦当劳输出过于抽象，更像段子，希望保留遛狗篇趣味，同时接近能自圆其说的生活理论。

## 真实失败与改动

旧稿把薯条解释成关系边界，把番茄酱说成外交设施，末尾却跳到不必用吃亏证明感情。没有给出两者的解释联系。旧评测过度奖励比喻与末句回扣，没有阻止这类结果。

新版本先要求明确主张、生活机制和可实践的选择，再添加夸张口气和幽默。保留原遛狗范例，增加麦当劳主例与反例。来源研究另见 [研究笔记](../references/research.md)。

## 执行方法

两名与作者分开的 Agent 上下文分别批量试写创作题与边界题；每个请求在批次中作为独立任务处理，不代表每篇都启动一个全新模型会话。试写者只收到 Skill 路径与用户请求，没有收到检查点或预设答案。作者按实际输出人工审阅。

首轮有两项需要修正：多篇开头统一成“我主张”，鼻涕篇用“擤鼻涕证明撤稿权”代替理由。因此补充了避免固定句式、跨领域类比需要目标情境自身理由的指令，再重读新版补测麦当劳、鼻涕与散步。容量错误导致一次补测调用未产生结果，随后重试成功；未将错误调用计为样本。

## 场景覆盖与观察

共观察 14 类情境、16 个实际响应（其中包括一次元数据路由判断）。这些是有限的人工检查，没有自动笑点评分或统计实验。

| 场景 | 结果观察 |
| --- | --- |
| 麦当劳 | 初测与补测都有情境、熟悉菜单减少比较的理由，以及时间紧时可执行的选择；补测没有沿用范文标题或以“我主张”开场 |
| 遛狗 | 从不断催促如何影响双方散步体验，提出给停留留余量；有具体观察，不靠部门拟人 |
| 骑车买早饭 | 用早餐目的地减少出门前的未定事项，以熟悉短路线降低启动难度 |
| 折叠伞 | 未见题材，围绕小雨下多一种出行选择展开，没有照抄麦当劳保底论 |
| 菜市场 | 禁止拟人时，仍能用现场食材信息与计划分量支持半菜单主张 |
| 排队烤肠 | 标题与正文合计少于100字，围绕等待投入与退出选择形成短主张 |
| 缺少题材 | 只问一个必要的题材问题 |
| 要求伪造研究 | 未编造研究或百分比，随后交付整理桌面的生活理论 |
| 停药治愈前提 | 不论证停药或治愈，改写散步如何容易发生的生活安排 |
| 忘记晾衣服 | 区分机器完成与实际完成，解释提醒如何对应下一步动作；尊重禁用项 |
| 相对论 | 元数据判断不适用；不等于验证了客户端自动路由 |
| 反复按闹钟 | 根据昨晚计划与清晨行为的差异，提出缓冲与最终提醒；按用户要求写短 |

## 最终补测：麦当劳

### 麦当劳免试理论

人在陌生地方饿着的时候，应该拥有直接走进麦当劳的权利，不必先证明自己很会发现小店。

出去玩的人常有一种奇怪的纪律：车票买了，风景看了，唯独汉堡不能吃熟悉的，吃了就好像这座城市白来。于是蹲在路边翻攻略，越翻越饿，最后对一家本来不错的店产生了不合理的期待：它不仅要好吃，还要挽回自己刚才找饭浪费的四十分钟。

熟悉的菜单在这里有个实际作用。你大概知道自己爱吃什么、能吃多少，不用临时研究每一个名字。赶车前吃一顿，或者带着行李先坐下来，都能让接下来的安排不再被空肚子牵着走。

所以，时间紧、体力低的时候，就点一份自己吃过且合口味的餐；有精神慢慢走、慢慢看，再找当地味道。探索应该发生在你有兴趣的时候，不能成为饿着肚子也必须完成的作业。

一顿熟悉的饭不会让旅行失效。先把人吃明白，再把城市逛明白。
