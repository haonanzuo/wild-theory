# 野生理论生成器 · Wild Theory

**把你随便过的一天，讲成你自创的一派。**

输入散步、遛狗、骑车买早饭，甚至擤鼻涕，得到一个理论名和一篇一本正经的短文：前面很扯，最后还有一点小道理。

这是一个纯文字 Agent Skill，不需要代码、API Key、额外插件或联网。它使用运行它的 AI 工具已有的模型能力；不保证每次生成同样的质量。

## 怎么用

安装后，在支持 `$技能名` 调用的工具中输入：

```text
用 $wild-theory 把“出门骑车买早饭”写成一个理论。
```

也可以加自己的要求：

```text
用 $wild-theory 写“洗衣机洗完了，我总忘记晾衣服”。
要很扯，最后有点道理，别写自律和强者。
```

```text
用 $wild-theory 写“排队买烤肠”，100字以内。
```

默认输出：**一个理论名 + 一篇约 180—350 中文字的短文**。没有前置问卷，也不附一份创作分析。用户指定的长度和风格优先。

## 安装

将本仓库作为一个完整的 Skill 文件夹，放进目标工具支持的技能目录。必须保留 `SKILL.md` 和 `references/` 的相对位置；只复制入口文件会缺失范例。

Codex 的个人技能目录安装示例：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/haonanzuo/wild-theory.git ~/.agents/skills/wild-theory
```

如果目标目录已经存在，请先检查已有内容，不要覆盖。安装后可新开一个对话，显式调用 `$wild-theory`。其他 Agent 的目录和调用语法以对应工具说明为准；本项目未逐端验证。

## 它怎样避免变成鸡汤

- 用题材特有的动作和物件推导，换个题材就得换套歪理。
- 中间先有具体笑点，最后才落回一点生活观察。
- 结尾回扣前文，不临时贴一个“要努力”“爱自己”。
- 不堆量子、熵增之类的大词，也不伪造研究、数据或名人背书。

这是荒诞写作工具。不要把创造的比喻当成医学、投资或学术依据。正常成品无需附加免责声明。

## 怎么改成自己的版本

在 `SKILL.md` 中修改默认长度和口气，在 `references/examples.md` 中换上你认可的原创范文。修改后用 `evals/cases.json` 的全新题目试写；只检查文件格式不能证明文案好笑。不要把每次偶然不好笑都补成一条永久禁令。
